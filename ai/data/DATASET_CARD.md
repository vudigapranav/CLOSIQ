# HeyHanger fashion pilot, schema 1

The repository includes 20 original synthetic outfit-ranking examples in ai/datasets/styling_seed.jsonl. There are zero reviewed garment photographs and no trained checkpoint. These authored examples have not received independent fashion review. The 500–1,000 target needs human-reviewed photos, labels and rights records. No private wardrobe, retail photos, DeepFashion or Fashionpedia assets have been ingested. The repository catalog describes mixed generated/photographed images without per-image permission for model training. Use it for development smoke tests only.

Keep a private JSONL manifest in this directory. Each record contains schema (1), id, group (same garment, shoot or outfit family), task, prompt, answer, source, license, attribution and rights_evidence. Garment records also contain image, a relative path under images. Accepted rights labels are CC0-1.0, CC-BY-4.0 owned-with-training-rights and project-authored-synthetic. Review the original grant, retain a receipt and carry attribution to any distributed model. The validator checks recorded evidence fields; a reviewer verifies the actual rights.

Garment answers require name, category, subcategory, primaryColor, pattern and formality. Record unknown for visually uncertain attributes. Leave out brand, price and exact textile composition. Rank tasks additionally carry a wardrobe dictionary of ID-to-description pairs and up to three candidate ID arrays. Their answers contain a 1-based choice and explanation.

Audit pilot coverage by task, colour, pattern, background, layering, season, occasion and footwear. Include sarees, kurtas, kurtis, salwar suits, lehengas, sherwanis and dupattas with reviewer-confirmed labels. Include unanswerable and ambiguous photos. Keep multiple photos of the same physical garment in one group. Review near-duplicates manually. The automated pass checks decoded pixels and duplicate instructions; stable group hashing preserves the held-out boundary.
