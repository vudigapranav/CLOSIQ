# HeyHanger project instructions

HeyHanger was called CLOSIQ until 2026-11-20. Use "HeyHanger" in prose and UI, "HeyHanger.ai" for the assistant and "HeyHanger-VLM" for the custom model family. Some CLOSIQ identifiers are kept on purpose for upgrades and live services; the list is in [CLAUDE.md](CLAUDE.md) (section 11) and [docs/BRANDING.md](docs/BRANDING.md).

Whenever Codex changes this repository, add a dated entry to the root [astra.md](astra.md) in the same change. Record what changed, which files were affected, and any verification or outstanding work Claude should know about.
